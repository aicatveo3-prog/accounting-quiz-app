# 회계학 공부 사이트 (2026 지방직 9급 회계학 기출)

## 사이트 열기

**`사이트 열기.bat`** 더블클릭 → 잠시 뒤 브라우저에 http://localhost:8765 가 열려요.
검은 창은 서버예요. 사용하는 동안 두고, 끝나면 닫으세요. 구글 로그인은 이 방식(또는 배포한 주소)에서만 돼요.

## 폴더

| 위치 | 내용 |
|---|---|
| `사이트 열기.bat` | 실행 버튼 |
| `site/` | 사이트 본체 (HTML·CSS·JS·문제 데이터). 사용법은 `site/README.md` |
| `firestore.rules` | Firebase 보안 규칙 (콘솔에 붙여 넣는 용도) |
| `문서/` | 기획서, 해설 검수표, 서버 연동 설정 방법 |
| `기출문제/` | 원본 기출 자료 |
| `.claude/` | 작업 도구 설정 (건드리지 않아도 돼요) |
