# 구글 로그인 + 서버 저장 설정 방법

사이트는 **Firebase**(구글의 무료 백엔드)를 서버로 써요. 직접 서버를 돌릴 필요가 없고, 개인 학습용 사용량은 무료 한도(Spark 요금제) 안이에요.
아래 순서대로 한 번만 설정하면 돼요. 코드는 이미 들어 있고, **연결 정보를 붙여 넣는 것**만 남아 있어요.

## 1. Firebase 프로젝트 만들기

1. https://console.firebase.google.com 에 구글 계정으로 접속
2. **프로젝트 추가** → 이름 입력(예: `gigul-note`) → Google 애널리틱스는 꺼도 돼요 → 만들기

## 2. 웹 앱 등록하고 연결 정보 복사

1. 프로젝트 첫 화면에서 웹 아이콘 **`</>`** 클릭 → 앱 닉네임 입력 → 앱 등록 (Hosting 체크는 안 해도 돼요)
2. 화면에 나오는 `firebaseConfig = { ... }` 를 복사
3. `site/js/firebase-config.js` 를 열어 `window.FIREBASE_CONFIG = null;` 줄을 아래처럼 바꿔요

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIza...",
  authDomain: "내프로젝트.firebaseapp.com",
  projectId: "내프로젝트",
  appId: "1:1234567890:web:abcdef"
};
```

이 값은 비밀번호가 아니라 "어느 프로젝트에 연결할지" 알려 주는 주소라서 공개 사이트에 들어가도 괜찮아요. 데이터를 지키는 건 4번의 보안 규칙이에요.

## 3. 구글 로그인 켜기

**빌드 → Authentication → 시작하기 → 로그인 방법 → Google** 선택 → 사용 설정 → 프로젝트 지원 이메일 선택 → 저장

## 4. 데이터베이스 만들고 보안 규칙 넣기

1. **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)` 권장
   - 모드: **프로덕션 모드**로 시작
2. **규칙** 탭을 열고, 프로젝트 맨 위 폴더의 `firestore.rules` 내용을 전부 붙여 넣고 **게시**

규칙의 뜻: 로그인한 본인만 자기 문서(`users/내 uid`)를 읽고 쓸 수 있어요. 다른 사람 문서와 다른 경로는 전부 막혀요.

## 5. 내 컴퓨터에서 테스트

`index.html` 더블클릭(`file://`)으로는 구글 로그인이 **동작하지 않아요.** 로컬 서버로 여세요.

```bash
cd site
python -m http.server 8765
```

브라우저에서 `http://localhost:8765` → 왼쪽 아래 **Google로 로그인**. `localhost` 는 Firebase가 기본으로 허용해요.

확인 방법: 문제를 하나 풀고 로그인 → 왼쪽 아래에 "서버에 저장됨" → Firebase 콘솔 Firestore에 `users/내 uid` 문서가 생겨 있으면 성공이에요. 다른 브라우저(또는 휴대폰)에서 같은 계정으로 로그인하면 기록이 따라와요.

## 6. 인터넷에 올릴 때

폴더 `site/` 를 정적 호스팅에 올리면 돼요(GitHub Pages, Firebase Hosting, Netlify 등). 올린 뒤 **한 가지**를 꼭 해야 해요.

- Firebase 콘솔 → **Authentication → 설정 → 승인된 도메인** 에 배포 주소(예: `내아이디.github.io`)를 추가
  - 안 하면 로그인할 때 "이 주소가 Firebase에 등록되지 않았어요" 메시지가 나와요

## 동작 방식

| 상황 | 동작 |
|---|---|
| 로그인 안 함 | 지금처럼 이 브라우저에만 저장 (로그인은 선택) |
| 처음 로그인 | 로그인 전에 쌓은 기록이 계정에 합쳐져 서버에 올라가요 |
| 문제를 풀거나 메모를 쓰면 | 약 4초 뒤 자동으로 서버에 저장, 탭을 닫거나 숨길 때 바로 저장 |
| 다른 기기에서 풀었다면 | 탭으로 돌아올 때(1분 이상 지났을 때)·네트워크가 다시 연결될 때 서버 내용을 받아 합쳐요 |
| 인터넷이 끊기면 | 이 기기에 계속 저장하고, 연결되면 30초 간격으로 재시도해요 |
| 로그아웃 | 서버에 마지막으로 저장한 뒤 이 기기의 기록을 지워요(공용 PC 보호). 다시 로그인하면 돌아와요 |
| 다른 계정으로 로그인 | 이전 계정의 기록과 섞이지 않아요 |
| 학습 기록 초기화 / 백업 가져오기 | 서버와 다른 기기에도 그대로 적용돼요(되살아나지 않아요) |

**합치는 규칙** (두 기기에서 따로 풀었을 때)
- 풀이 기록: 제출된 쪽 → 더 최근에 수정한 쪽이 남아요. 버린 기록은 되살아나지 않아요
- 메모·북마크: 항목별로 더 최근에 고친 쪽이 남아요. 한쪽에서 지웠으면 지워져요
- 같은 문제의 같은 메모를 두 기기에서 동시에 고치면 나중에 고친 쪽이 이겨요(글자 단위 병합은 아니에요)

**저장 구조**: 사용자마다 문서 1개(`users/{uid}` — `rev`, `data`(JSON 문자열), `updatedAt`). 보안 규칙이 문서 크기를 약 900KB로 제한해요. 메모를 아주 많이 쓰거나 풀이 기록이 수천 건이 되면 한계에 닿을 수 있고, 그때는 기록별 문서로 나누는 작업이 필요해요.

## 문제가 생기면

| 메시지 | 원인과 해결 |
|---|---|
| "서버 연결 설정이 필요해요" | `firebase-config.js` 가 아직 `null` 이에요 → 2번 |
| "이 주소에서는 로그인할 수 없어요" | `file://` 로 열었어요 → 5번처럼 로컬 서버로 열기 |
| "이 주소가 Firebase에 등록되지 않았어요" | 승인된 도메인에 현재 주소 추가 → 6번 |
| "Google 로그인이 켜져 있지 않아요" | 3번 |
| 왼쪽 아래에 "저장하지 못했어요" 가 계속 보임 | Firestore를 안 만들었거나 규칙 미게시(4번), 또는 오프라인. 브라우저 개발자 도구 콘솔의 "서버 동기화 실패" 오류 코드 확인(`permission-denied` 면 규칙 문제) |
| 팝업이 안 뜸 | 브라우저 팝업 차단 해제 |
