- 모바일: 하단 탭 4개 (플래너, 기출, 오답, 기록). 메모와 설정은 더보기
- 풀이 화면에서는 사이드바를 접어 풀이 공간을 최대한 확보한다

## 4. 화면별 상세 설계

### 4-1. 플래너 (홈)
- **D-day 카드**: 다음 시험 이름과 남은 일수. 시험일이 없으면 "시험일 설정하기" 안내(빈 상태)
- **주간 목표 카드**: "이번 주 N문제 중 M문제" 진행 막대와 요일별 체크
- **오늘 할 일**: 자동 생성. 이어 풀기 1건 + 오늘 복습할 오답 N건
- **영역별 진도**: 재무회계, 원가회계, 정부회계의 푼 문제 비율
- **최근 기록**: 최근 풀이 5건(날짜, 문제, 정오답)
- 첫 방문(데이터 없음): 시험일과 주간 목표를 묻는 2단계 시작 안내

### 4-2. 기출 문제 목록
- 회차 카드: 시험명, 문항 수, 제한 시간, 내 최고 점수, 진행도
- 카드 선택 → 시작 방식 선택 창
  - 연습: 시간 제한 없음, 선택 즉시 정답과 해설 확인
  - 실전: 20분 타이머, 제출 후 채점
  - 오답만: 틀린 문제와 북마크 문제만
- 문항 필터: 영역, 유형(개념/계산), 상태(안 푼/맞힌/틀린/북마크)

### 4-3. 풀이 화면 (A-1, 핵심)
레이아웃 (데스크톱)
```
┌────────────────────────────────────────────────────────────┐
│ ≡ 2026 지방직 회계학 · 4/20      ⏱ 14:32(실전)   ☆   [제출]│
├──────────────────────────────┬─────────────────────────────┤
│ 4. 지문                      │ 풀이 메모                   │
│   [보기 표 / 분개 컴포넌트]   │ [T계정][월할][분개][타임라인]│
│   ① ② ③ ④ 선택지             │ (자유 입력 영역)            │
│                              │ 🧮 계산기                   │
├──────────────────────────────┴─────────────────────────────┤
│ ◀ 이전                  문항 패널 ▲                  다음 ▶ │
└────────────────────────────────────────────────────────────┘
```
- 문제 영역: 지문, 보기(표/분개 전용 컴포넌트), 선택지 4개(큰 터치 영역)
- 메모 영역: 템플릿 버튼으로 틀 삽입 — T계정, 월할(×/12), 분개 표, 타임라인. 문제별 자동 저장
- 계산기: 간단 사칙연산, 결과를 메모에 붙이기
- 문항 패널: 아래에서 올라오는 번호 목록(푼/안 푼/북마크 구분)
- 하단: 이전/다음. 마지막 문항에서는 "제출"
- 모바일: 메모는 서랍으로 접혀 있고, "메모 열기" 버튼으로 연다
- 단축키: 1~4 선택, ←/→ 이동, M 메모, B 북마크
- 연습 모드: 선택 후 "정답 확인" → 정답·해설 표시. 실전 모드: 제출 전까지 정답 비공개

### 4-4. 결과 화면
- 점수(문항당 5점 기준 100점 환산), 소요 시간, 정답 수
- 영역별 정답률 막대 3개
- 문항 칩 20개(맞음/틀림/미풀이). 칩 선택 → 해당 문항 해설로 이동
- 버튼: "틀린 문제 다시 풀기", "오답노트에 담기"(틀린 문제는 자동 담김)

### 4-5. 오답노트
- 틀린 문제와 북마크 문제 목록. 영역·유형 필터
- 복습 일정: 틀린 날 기준 1일, 3일, 7일 뒤 복습 대상으로 표시(단순 간격 복습)
- 재풀이에서 맞히면 일정을 뒤로 미루고, 틀리면 처음부터 다시

### 4-6. 내 메모
- 내가 쓴 풀이 메모 모아보기, 문제 번호·영역·키워드 검색
- 메모에서 해당 문제로 바로 이동

### 4-7. 통계
- 영역별·유형별(개념/계산) 정답률
- 문항별 평균 풀이 시간
- 주간 학습량(문제 수)

### 4-8. 설정
- 시험일(이름 + 날짜), 주간 목표 문제 수
- 화면 모드(라이트/다크/시스템)
- 데이터 내보내기·가져오기(JSON 파일). 브라우저 저장소가 지워질 때를 대비한 백업
- 학습 기록 초기화(확인 창 필수)

## 7. 기술 방향

- 정적 웹사이트(서버 없음). 문제는 JSON, 학습 기록은 브라우저 저장소
- 배포: GitHub Pages 등 무료 정적 호스팅
- 후보 스택: 가벼운 프레임워크(React 또는 Svelte) + 정적 빌드. 확정은 구현 단계에서 결정
- 로그인과 기기 간 동기화는 2차 과제(필요할 때 추가)

## 8. 구현 단계 제안

1. **1차 (완료, `site/` 폴더)**: 문제 데이터 20문항(표·분개 포함) + 풀이 화면(A-1) + 결과 화면. 데이터는 `file://`로도 열리도록 JS 파일로 구현(구조는 JSON과 동일). 사용법은 `site/README.md`
2. **2차 (완료, `site/` 폴더)**: 플래너 홈(D-day, 주간 목표, 오늘 할 일, 영역별 진도, 최근 기록) + 기출 목록(`#/exams`) + 시작 방식 선택 + 사이드바 정리. 시험일·주간 목표는 플래너의 설정 창에서 수정(별도 설정 화면은 3차)
3. **3차 (완료, `site/` 폴더)**: 오답노트(1·3·7일 복습, 세 번 맞히면 익힌 문제), 내 메모 모아보기·검색, 통계, 설정(시험 정보·화면 모드·백업/가져오기·기록 초기화), 모바일 하단 탭바
4. **4차**: 해설 작성과 추가 기출 입력, 모바일 다듬기, 배포
   - 해설 초안 20문항 작성 완료(AI 초안·검수 전, `해설_검수표.md` 참고). 남은 일: 해설 검수, 추가 기출, 배포

## 9. 결정이 필요한 것

- 사이트 이름 (가칭: 회계 기출 노트)
- 점수 계산: 문항당 5점(20문항 100점)으로 가정함. 맞는지 확인 필요
- 해설: 직접 작성 / AI 초안 + 직접 검수 / 나중에
- 공개 여부: 혼자 사용인지, 공개 배포인지(공개 시 기출 출처·저작권 표기 필요)
- 추가 기출(국가직, 서울시, 이전 연도)의 확보 계획
