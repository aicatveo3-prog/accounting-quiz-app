# 회계 기출 노트 (1차 버전)

회계학 기출을 한 번에 한 문제씩 풀고, 풀이 메모를 남기는 정적 웹사이트입니다. 서버·빌드 도구가 필요 없어요.

## 실행

- 프로젝트 맨 위의 **`사이트 열기.bat`** 을 더블클릭하면 서버가 켜지고 브라우저가 열려요(구글 로그인도 이 방식에서 동작해요)
- `index.html` 더블클릭도 되지만 구글 로그인은 안 돼요. (폰트는 인터넷 연결 시 Pretendard, 없으면 시스템 글꼴)
- 로컬 서버로 열고 싶다면 이 폴더에서:

```bash
python -m http.server 8765
```

브라우저에서 `http://localhost:8765` 로 접속하세요.

## 구글 로그인 · 서버 저장 (새로 추가)

- 왼쪽 아래 **Google로 로그인**(모바일은 위쪽 사람 아이콘). 로그인은 선택이고, 로그인하면 풀이 기록·메모·북마크가 서버(Firebase Firestore)에 자동 저장돼서 다른 기기에서도 이어져요
- **Firebase 연결 정보를 넣기 전에는 지금처럼 이 브라우저에만 저장돼요.** 설정 순서는 프로젝트 폴더의 `문서/서버연동_설정방법.md`, 연결 정보는 `js/firebase-config.js` 에 넣어요
- `file://`(더블클릭)으로 연 상태에서는 구글 로그인이 안 돼요. `python -m http.server` 로 열거나 배포한 주소에서 쓰세요
- 구조: `js/cloud.js`(Firebase 어댑터 — 앱은 이 파일만 통해 서버와 대화), `js/merge.js`(기기 간 병합 규칙), `../firestore.rules`(내 문서는 나만 읽고 쓰기)
- 로그아웃하면 이 기기의 기록은 지워지고(서버에는 남아요), 로그인하면 돌아와요

## 풀이 화면 사용법 (최근 변경)

- **연습 모드는 시간을 표시하지 않아요.** 풀이 화면에도, 연습 결과 화면에도 시간이 나오지 않아요. 시간은 **실전 모드(20분 타이머)** 에서만 보여요. 통계의 "실전 풀이 시간"과 "오래 걸린 문제"도 실전 기록만 써요
- **문제 이동은 화면 위쪽 슬라이더**로 해요. 손잡이를 **끌면 지나가는 문제로 바로 이동**하고(마우스·터치), 슬라이더를 누른 채 방향키 `←/→`로도 움직여요. 오른쪽에는 현재 위치 `7 / 20` 하나만 보여요
- **PC에서는 가운데 카드형 레이아웃**이에요. 문제는 화면 가운데 카드(폭 720px) 안에 있고, 메모를 열면 오른쪽에 메모 패널(340px)이 붙어서 두 칸이 돼요(태블릿 가로 모드처럼). 메모 패널은 스크롤해도 따라다녀요
  - 위쪽 **메모 / 메모 닫기** 버튼(또는 `M` 키)으로 열고 닫아요. PC에서는 **마지막 선택을 기억**해서 다른 문제로 넘어가도, 새로고침해도 그대로예요. 처음에는 열려 있어요
  - 모바일에서는 카드 테두리 없이 화면 폭을 쓰고, 메모는 아래에서 올라오는 서랍이에요(문제를 넘기면 닫혀요)
- **이전 · 다음 버튼은 문제 카드 안, 선택지 아래**에 있어요. 이전은 왼쪽, 다음은 오른쪽 끝이고, 마지막 문제에서는 다음 자리가 **제출하기**로 바뀌어요. 화면 맨 아래 고정 바는 없어요
- 카드 오른쪽 위에 `푼 문제 N / 20`(정답 확인 화면에서는 `정답 N / 20`)이 작게 나와요
- **다시 풀기**
  - 연습에서 정답을 확인한 문제 아래 **"이 문제 다시 풀기"**: 그 문제의 답과 확인 기록을 지우고 다시 풀어요
  - 연습 화면 위쪽 **"처음부터"**: 이 연습의 답을 모두 지우고 1번부터 다시 시작해요(풀이 메모는 남아요)
  - 결과 화면의 **"정답 확인"에서 "이 문제 다시 풀기"**: 그 한 문제를 새 연습으로 풀어요
  - 결과 화면의 "틀린 N문제 다시 풀기", "처음부터 다시 풀기", 오답노트의 "다시 풀기"는 그대로예요

## 지금 화면에서 보류한 기능 (기능 스위치)

`js/app.js` 맨 위의 `FEATURES` 에서 `false` 인 기능은 화면에서만 숨겨요. 코드와 데이터는 그대로 있어서 `true` 로 바꾸면 다시 나타나요.

| 스위치 | 숨긴 것 | 지금 화면 |
|---|---|---|
| `explanations: false` | 해설 문장, "AI 초안" 표시 | 정답 확인 시 "정답이에요 / 정답은 ③번이에요"만 표시 |
| `planner: false` | 플래너 홈 (D-day, 주간 목표, 오늘 할 일) | 첫 화면이 **기출 문제** 목록 |
| `memos: false` | 내 메모 모아보기 | 풀이 화면의 메모는 그대로 쓸 수 있고, 모아보는 화면만 숨김 |
| `settings: false` | 설정 (시험일, 화면 모드, 백업/가져오기/초기화) | 화면 모드는 사이드바 맨 아래 버튼으로 바꿀 수 있어요 |

- 지금 메뉴: **기출 문제 · 오답노트 · 통계**
- 숨긴 주소(`#/memos`, `#/settings`)로 들어가면 첫 화면으로 돌아와요
- 설정 화면을 숨겨서 **백업 파일 만들기·가져오기·초기화**도 화면에서 쓸 수 없어요. 학습 기록은 브라우저에만 저장되니, 필요해지면 `settings: true` 로 켜세요
- 해설 20문항 초안은 데이터 파일(`data/exam-2026-local-9-acc.js`)에 그대로 남아 있어요

## 4차에 추가된 것 (해설 초안 — 현재 화면에서는 숨김)

- 20문항 모두 해설이 들어갔어요(`data/exam-2026-local-9-acc.js` 의 `explanation`). 줄바꿈이 화면에 그대로 나와요
- 모두 **AI 초안 · 검수 전**이에요. 해설 옆에 노란 "AI 초안 · 검수 전" 표시가 붙어요
- 계산형 10문항은 해설과 별개로 직접 계산해서 공식 정답표와 일치하는 걸 확인했어요. 개념형은 기준서·규칙 원문 대조가 필요해요
- 검수 방법과 문제별 확인 포인트는 프로젝트 폴더의 `문서/해설_검수표.md` 에 있어요
- 검수가 끝난 문제는 데이터 파일에서 `explanationStatus: "draft"` 를 `"reviewed"` 로 바꾸면(또는 줄을 지우면) 초안 표시가 사라져요

## 3차에 추가된 것 (오답노트 · 내 메모 · 통계 · 설정)

- 사이드바 6개 메뉴가 모두 열렸어요. 모바일은 하단 탭(플래너·기출·오답노트·내 메모·통계) + 상단의 설정·화면 모드 버튼
- 오답노트(`#/wrong`): 틀린 문제를 복습 일정에 따라 관리
  - 틀리면 다음 날 → 맞히면 3일 뒤 → 맞히면 7일 뒤 → 세 번 맞히면 "익힌 문제". 다시 틀리면 처음 단계로 돌아가요
  - 복습 일정은 제출된 풀이 기록을 처음부터 다시 계산해서 만들어요(별도 저장 없음)
  - 보기: 전체 / 오늘 복습 / 북마크 / 익힌 문제, 문제별 다시 풀기·해설·북마크, "오늘 복습 시작" "전체 오답 풀기"
  - 플래너의 "오늘 복습할 문제" 와 기출 목록의 "오답만" 이 같은 데이터를 써요
- 내 메모(`#/memos`): 문제별 풀이 메모 모아보기, 내용·번호·단원 검색, 문제 다시 풀기, 삭제
- 통계(`#/stats`): 푼 문항·제출 횟수·전체 정답률·총 학습 시간, 영역·유형별 정답률, 약한 단원, 점수 추이(전체 풀이), 오래 걸린 문제, 최근 8주 학습량
- 설정(`#/settings`): 시험 이름·시험일·주간 목표, 화면 모드(시스템/라이트/다크), 백업 파일 만들기·가져오기, 학습 기록 초기화
  - 가져오기는 알려진 형식만 골라서 읽고, 다른 앱 파일이나 손상된 파일은 거절해요. 가져오면 지금 기록은 백업 내용으로 바뀌어요
  - 초기화는 "초기화"를 직접 입력해야 진행돼요. 시험 정보와 화면 모드는 남아요

## 2차에 추가된 것 (플래너 홈)

- 홈이 플래너(`#/`)로 바뀌었고, 기출 목록은 `#/exams` 로 이동했어요. 사이드바: 플래너 · 기출 문제 (오답노트·내 메모·통계·설정은 준비 중)
- D-day 카드: 시험 이름·시험일을 설정하면 `D-138`, `D-DAY`, `D+3` 으로 표시
- 주간 목표 카드: 이번 주(월~일) 푼 문제 수 / 목표, 요일별 체크, 목표 달성 표시, 연속 학습 일수
  - "푼 문제"는 새로 답을 고른 문항 수예요. 같은 문항의 답을 바꾸는 건 다시 세지 않아요
- 오늘 할 일: 이어 풀기 · 틀린 문제 다시 풀기 · 오늘의 한 문제(아직 안 푼 가장 앞 번호) · 오늘 학습 완료
- 영역별 진도(푼 문항 / 전체), 최근 기록 5건
- 시험일·주간 목표는 플래너의 "시험일 설정" 버튼에서 바꿔요 (설정 화면은 3차 예정)

## 1차에 들어 있는 것

- 기출 목록 + 시작 방식 선택: 연습 / 실전(20분 타이머, 시간 종료 시 자동 제출) / 오답만
- 풀이 화면(A-1 템플릿 메모형): 문제 + 보기(표·분개) + 선택지, 풀이 메모(T계정·월할·분개·타임라인 템플릿), 계산기, 북마크, 문항 번호 바
- 결과 화면: 점수, 정답 수, 소요 시간, 영역별·유형별 정답률, 문항별 결과, 틀린 문제 다시 풀기
- 해설 보기: 번호를 눌러 정답과 내 답 확인 (해설 문장은 아직 없음)
- 이어 풀기, 라이트/다크 모드, 모바일 레이아웃
- 단축키: `1~4` 선택, `←/→` 이동, `Enter` 정답 확인(연습), `M` 메모, `B` 북마크

## 폴더 구조

```
site/
├─ index.html
├─ css/style.css
├─ js/app.js
├─ js/merge.js                     ← 기기 간 병합 규칙
├─ js/cloud.js                     ← 구글 로그인 + 서버 저장 어댑터 (Firebase)
├─ js/firebase-config.js           ← Firebase 연결 정보 (설정 전에는 null)
└─ data/exam-2026-local-9-acc.js   ← 문제 데이터 (20문항)
```

## 데이터

- 학습 기록과 메모는 브라우저 `localStorage`(`gigul-note.v1`)에 저장돼요. 로그인하지 않으면 브라우저 데이터를 지울 때 사라져요. 로그인하면 서버에도 저장돼요.
- 해설 추가: 데이터 파일에서 문제의 `explanation: null` 을 문장으로 바꾸면 연습·해설 화면에 나타나요.
- 기출 추가: `data/` 에 같은 형식의 파일을 만들고 `index.html` 에 `<script>` 한 줄을 추가하세요.
- 13번의 빈칸 표는 원본 PDF에서 일부 칸이 비어 있어서 그대로 옮겼어요.
