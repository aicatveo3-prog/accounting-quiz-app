🔍 문제 확인
"일반목적재무보고에 대한 설명으로 옳지 않은 것은?"

정답: ③번

🧠 핵심 배경 이론: 일반목적재무보고란?
일반목적재무보고서(General Purpose Financial Report)는 특정 이용자 한 명을 위한 것이 아니라, 다양한 이해관계자들이 공통적으로 사용할 수 있도록 만든 재무보고서입니다.

왜 "일반목적"이라고 할까?
구분	설명
일반목적 재무보고서	여러 이용자가 공통으로 필요로 하는 정보를 제공
특수목적 재무보고서	특정 이용자(예: 세무서, 특정 은행)의 요구에 맞춰 작성
💡 핵심 포인트: "모든 사람의 모든 요구"를 다 충족시키는 게 아니라, "대부분의 사람이 공통으로 필요로 하는 정보"를 제공하는 것!

📝 보기별 상세 해설
✓ ①번: 재무보고서는 정확한 서술보다는 상당 부분 추정, 판단 및 모형에 근거한다.
→ 옳은 설명입니다.

재무보고서에는 감가상각비(내용연수 추정), 대손충당금(회수불능 추정), 공정가치 측정(모형 사용) 등이 포함됩니다.
이런 항목들은 100% 정확한 숫자가 아니라, 경영진의 추정과 판단에 의존합니다.
개념체계에서도 "재무보고서는 정확한 묘사라기보다는 추정, 판단, 모형에 상당 부분 근거한다"고 명시하고 있습니다.
✓ ②번: 경영진은 필요한 재무정보를 내부에서 구할 수 있어 일반목적재무보고서에 의존할 필요가 없다.
→ 옳은 설명입니다.

경영진은 회사 내부 사람이므로, 원하는 정보를 직접 만들어 볼 수 있습니다.
예: 부서별 매출, 제품별 원가 등 → 내부 관리회계 시스템으로 확인 가능
따라서 경영진은 일반목적재무보고서의 주요 이용자에 포함되지 않습니다.
일반목적재무보고서는 외부 이용자(투자자, 대여자, 채권자 등)를 위한 것!
✗ ③번 (정답): 일반목적재무보고서는 현재 및 잠재적 투자자, 대여자와 그 밖의 채권자가 필요로 하는 모든 정보를 제공하여야 한다.
→ 옳지 않은 설명입니다!

이것이 정답인 이유를 자세히 설명하겠습니다:

! "모든 정보"라는 표현이 핵심 함정!

틀린 표현 (③번)	올바른 표현
모든 정보를 제공해야 한다	공통으로 필요한 정보를 제공한다
일반목적재무보고서는 이용자들이 필요로 하는 "모든" 정보를 제공할 수 없고, 제공하도록 의도된 것도 아닙니다.
각 이용자마다 원하는 정보가 제각각 다르기 때문에, 전부 다 담는 것은 불가능합니다.
개념체계 원문에서도 명확히 말합니다:
"일반목적재무보고서는 주요 이용자가 필요로 하는 모든 정보를 제공하지는 않으며, 제공할 수도 없다."

✓ ④번: 많은 현재 및 잠재적 투자자, 대여자 및 그 밖의 채권자는 정보를 제공하도록 보고기업에 직접 요구할 수 없고, 재무정보의 많은 부분을 일반목적재무보고서에 의존해야만 한다.
→ 옳은 설명입니다.

일반 투자자나 채권자는 기업에 "나에게 맞는 보고서를 만들어 달라"고 직접 요구할 권한이 없습니다.
그래서 이들은 기업이 공시하는 일반목적재무보고서에 의존할 수밖에 없습니다.
이것이 바로 일반목적재무보고서가 존재하는 이유이기도 합니다!
📌 한눈에 정리
일반목적재무보고서의 핵심 포인트:

1. 추정·판단에 근거  ✓ → 100% 정확한 서술이 아님
2. 경영진은 불필요    ✓ → 내부에서 직접 정보 획득 가능
3. "모든" 정보 제공?  ✗ → "공통" 정보만 제공 (모든 ≠ 공통)
4. 외부이용자 의존    ✓ → 직접 요구 불가, 보고서에 의존
💡 시험 꿀팁
이런 문제에서 "모든", "항상", "반드시", "어떠한 경우에도" 같은 극단적 표현이 나오면 의심하세요!

회계 개념체계는 대부분 **"완벽"보다는 "유용성"**을 추구하기 때문에, "모든 정보를 제공한다"는 식의 절대적 표현은 거의 틀린 선지입니다. 😊




🔍 문제 확인
"재무제표 표시에 대한 설명으로 옳지 않은 것은?"

정답: ④번 (내 답 ③번 → 틀림 😢)

🧠 핵심 배경 이론: "상계표시"란?
상계(相計)가 뭐야?
상계 = 서로 빼서(차감해서) 순액(net)으로 보여주는 것

예시)
매출채권        1,000원
대손충당금      △100원
─────────────────────
순액 표시:       900원   ← 이게 상계? 아닌가? 🤔
💡 여기서 중요한 개념이 나옵니다. "진짜 상계"와 "상계가 아닌 것"을 구분하는 게 이 문제의 핵심!

📐 이론 정리: 상계표시의 원칙
● 대원칙: 상계 금지!
K-IFRS(한국채택국제회계기준)는 원칙적으로 상계를 금지합니다.

"기준서에서 요구하거나 허용하지 않는 한, 자산·부채 그리고 수익·비용은 상계하지 아니한다."

왜 금지할까?

상계하면 정보가 사라져 버리기 때문!
예: 매출 1,000 + 매입 800을 상계해서 "200"만 보여주면, 기업의 실제 영업규모를 알 수 없음
○ 예외: 상계가 허용되는 경우
**"거래의 실질을 반영"**하는 경우에는 상계 표시가 허용됩니다.

📝 보기별 상세 해설
✓ ①번: 부적절한 회계정책은 공시나 주석 또는 보충 자료를 통해 설명하더라도 정당화될 수 없다.
→ 옳은 설명입니다.

잘못된 회계처리를 하고, 주석에 "이렇게 한 이유는..."이라고 설명한다고 해서 면죄부가 되지 않습니다.
아무리 자세히 설명해도 "부적절한 것은 부적절한 것"
주석은 보충 설명이지, 잘못된 처리를 정당화하는 수단이 아닙니다!
비유: 시험에서 틀린 답을 쓰고 옆에 "이렇게 쓴 이유는..."이라고 적어도 점수를 받을 수 없는 것과 같습니다 😅

✓ ②번: 한국채택국제회계기준에서 요구하거나 허용하지 않는 한 자산과 부채 그리고 수익과 비용은 상계하지 아니한다.
→ 옳은 설명입니다.

이것이 바로 상계 금지의 대원칙입니다!

상계 금지 대상:
┌──────────────────────┐
│  자산  ↔  부채       │  상계 ✕
│  수익  ↔  비용       │  상계 ✕
└──────────────────────┘
         ⚠️ 단, 기준서가 요구하거나 허용하면 OK
✓ ③번: 동일 거래에서 발생하는 수익과 관련비용의 상계표시가 거래나 그 밖의 사건의 실질을 반영한다면 그러한 거래의 결과는 상계하여 표시한다.
→ 옳은 설명입니다! (내가 이걸 틀린 답으로 골랐는데... 옳은 설명이었음 😭)

구체적 예시로 이해해보자:

상황	처리
유형자산 처분: 처분대금 500, 장부금액 300	처분이익 200으로 순액 표시 ✓
외환거래: 외환차익 100, 외환차손 70	순액 30으로 표시 가능 ✓
유형자산을 팔 때, 수익 500 / 비용 300 으로 총액 표시하면 오히려 이상하죠?
"처분이익 200"이라고 **순액(상계)**으로 표시하는 것이 거래의 실질을 더 잘 반영합니다.
이것은 기준서가 허용하는 상계이므로 문제 없음!
✗ ④번 (정답): 재고자산에 대한 재고자산평가충당금과 매출채권에 대한 대손충당금과 같은 평가충당금을 차감하여 관련 자산을 순액으로 측정하는 것은 상계표시에 해당한다.
→ 옳지 않은 설명입니다!

! 이것이 이 문제의 핵심 함정입니다!

왜 상계가 아닐까?
매출채권        1,000
대손충당금      △100
──────────────────
순액 표시:       900  ← 이건 상계가 ✗ 아닙니다!
"평가충당금을 차감하는 것"은 상계가 아니라 "측정(measurement)"입니다!

구분	상계표시	평가충당금 차감
본질	서로 다른 항목을 빼는 것	같은 자산의 가치를 조정하는 것
예시	매출 - 매입 = 순이익	매출채권 - 대손충당금 = 순실현가능액
해당 여부	진짜 상계 ⭕	상계 아님 ✗
쉬운 비유로 이해하기
🏠 내 집의 시가가 5억인데, 감가상각 1억을 빼서 4억으로 표시하는 것은...

집값(자산)에서 뭔가 다른 것(부채)을 뺀 게 아니라
집 자체의 현재 가치를 더 정확하게 보여주는 것
이건 **"측정"**이지 **"상계"**가 아닙니다!
K-IFRS 원문 근거
"자산을 평가충당금을 차감한 순액으로 보고하는 것(예: 재고자산의 재고자산평가충당금, 매출채권의 대손충당금)은 상계가 아니다."

📌 한눈에 정리
상계 vs 상계가 아닌 것

┌─────────────────────────────────────────────┐
│         상계(Offsetting) ⭕                  │
│  • 자산 vs 부채를 서로 빼서 표시             │
│  • 수익 vs 비용을 서로 빼서 표시             │
│  • 예: 유형자산 처분이익(순액)               │
│       원칙적 금지! (기준서 허용 시에만 OK)   │
├─────────────────────────────────────────────┤
│         상계 아님 ✗                          │
│  • 평가충당금 차감 (측정의 문제)             │
│  • 예: 매출채권 - 대손충당금                 │
│       재고자산 - 재고자산평가충당금           │
│  → 이건 자산의 "가치를 조정"하는 것!         │
└─────────────────────────────────────────────┘
💡 시험 꿀팁
"평가충당금 차감 = 상계"라고 낚는 문제가 매우 자주 출제됩니다!

기억하세요:

상계 = 서로 다른 성격의 항목끼리 빼는 것
평가충당금 차감 = 같은 자산의 가치를 정확하게 보여주기 위한 측정 과정
📝 "충당금 차감 ≠ 상계" 이 한 줄만 기억하면 이 유형은 절대 안 틀립니다! 💪



정답: ②번 ₩40,000

🧠 핵심 배경 이론: "선수수익"이란?
먼저, 발생주의를 이해하자!
회계에서 수익은 "현금을 받았을 때"가 아니라 "서비스를 제공했을 때" 인식합니다.

현금주의: 돈 받았다 → 수익!  (✗ 회계에서는 이렇게 안 함)
발생주의: 서비스 제공했다 → 수익!  (✓ 회계 원칙)
선수수익(선수임대료)이 뭐야?
선수수익 = 돈은 먼저 받았지만, 아직 서비스를 제공하지 않은 금액

쉬운 비유:

🏠 세입자가 1년치 월세를 미리 줬어요. 돈은 받았지만, 아직 12개월 동안 건물을 빌려줘야 할 의무가 남아있죠?
→ 이 "아직 안 갚은 의무" = 선수임대료(부채)

구분	의미
현금 수취	돈을 받음 (은행 잔고 ↑)
수익 인식	서비스를 제공해서 벌었다고 인정
선수수익	돈은 받았지만 아직 빚진 서비스 (= 부채!)
📐 풀이 공식: T계정으로 이해하기
선수임대료는 부채이므로, T계정의 흐름을 따라가봅시다.

선수임대료 T계정
        선수임대료 (부채)
    ─────────────────────────
    차변(감소)  │  대변(증가)
    ────────────│────────────
                │ 기초잔액   30,000
    수익인식    │ 현금수취   50,000
     40,000     │
    ────────────│────────────
                │ 기말잔액    ???
부채의 기본 공식
기초잔액 + 증가(현금수취) - 감소(수익인식) = 기말잔액

🔢 실제 계산
주어진 정보 정리
항목	금액
기초 선수임대료	₩30,000
당기 현금수취액	₩50,000
당기 임대료수익 (포괄손익계산서)	₩40,000
기말 선수임대료	???
계산 과정
기말 선수임대료 = 기초 선수임대료 + 현금수취액 - 임대료수익

              = 30,000 + 50,000 - 40,000

              = ₩40,000 ✓
흐름을 말로 풀어보면:
기초에 ₩30,000 → 작년에 미리 받아놓고 아직 서비스 안 한 금액
올해 ₩50,000 현금 수취 → 새로 돈을 받음 → 선수임대료(부채) 증가!
총 의무: ₩80,000 (30,000 + 50,000)
올해 실제 서비스 제공: ₩40,000 → 수익 인식 → 선수임대료(부채) 감소!
기말에 남은 의무: ₩40,000 (80,000 - 40,000)
▪ 분개로 확인하기
① 당기 중 임대료 현금 수취 시
(차) 현금          50,000
    (대) 선수임대료     50,000
→ "돈은 받았지만, 아직 빌려줄 의무가 있으니 부채!"
② 기말 수익 인식 시 (서비스 제공한 만큼)
(차) 선수임대료     40,000
    (대) 임대료수익     40,000
→ "서비스를 제공했으니, 부채를 줄이고 수익으로 인식!"
📌 한눈에 정리
선수수익의 흐름:

  현금 수취         서비스 제공
  (부채 증가)       (부채 감소, 수익 인식)
      │                  │
      ▼                  ▼
┌──────────────────────────────────┐
│  기초 선수임대료      30,000     │
│  (+) 현금수취         50,000     │

💡 시험 꿀팁
선수수익 문제는 항상 이 한 줄 공식으로 풀립니다:

📝 기말 선수수익 = 기초 선수수익 + 현금수취 - 수익인식

반대로 미수수익 문제가 나오면:

📝 기말 미수수익 = 기초 미수수익 + 수익인식 - 현금수취

선수수익 (먼저 받음)	미수수익 (아직 못 받음)
돈 받음 → 부채 ↑	수익 발생 → 자산 ↑
서비스 제공 → 수익 & 부채 ↓	돈 받음 → 자산 ↓
이 대비 구조를 기억해두면 어떤 변형 문제가 나와도 풀 수 있습니다! 💪
